# GHL Funnel Playbook

This skill lives in the playbook folder (repo https://github.com/shuri-lab/GHL-connection-skill; the folder may be named `GHL-connection-skill` or `ghl-funnel-playbook`).

1. Find the folder. It is three levels up from this file (`../../../START-HERE.md`). If the skill was copied elsewhere, look for a clone, or ask the person to clone the repo and give you its path.
2. Read `knowledge/safety-rules.md`, then `START-HERE.md`, then follow it from Stage 0.
3. To build or improve the pages themselves (copy, design, speed), also use the Sales Page Playbook: https://github.com/shuri-lab/landing-pages-skill.
4. For **the test**, read `test/TEST.md` first.

Never type passwords or card numbers. Never delete or change anything outside the funnel you are building without the person's explicit yes.
